# 🎉 Давай играй

Приложение выросло из игр для пар в пять форматов сразу: **💕 Игры для пар 18+**, **🎉 Игры для компании**, **🧸 Игры с детьми**, **💼 Бизнес игры** (обучающие мини-игры для тимбилдинга и деловых встреч) и **📱 Игры для одного** (скоротать время в одиночку). Главный экран — хаб с кнопкой каждого формата, а звук и служебные кнопки (обновить приложение / сбросить прогресс / установить / резервная копия) собраны в глобальном меню — кнопка «☰» на главном экране.

Работает как обычное приложение (PWA): без интернета и без сервера, устанавливается на телефон через «Добавить на экран «Домой»» и открывается без адресной строки браузера — всё остаётся только между вами.

## Игры для пар 18+

Давно мечтали открыть друг друга ближе, а стыдно — или боитесь, что «это» не поймёт? Рутина в отношениях начинается не с того, что чувств уже нет — а с того, что не хватает повода сказать: «а давай сегодня попробуем что-то новое?»

По очереди вытягиваете карточку, вопрос или задание — и выбираете вместе, куда двигаться дальше. Возможности бывают разные: от лёгкого флирта и вопросов на сближение до самых смелых фантазий, — от «видим только совпадения, а не ответы» («Твои желания», «Тайные ответы») до открытого диалога с общим счётом и именами победителей. Ни давления, ни счётчиков «нормы» и рекомендаций про секс-шоп — только вы двое, ваш темп и то, как ваши желания совпадают.

| Игра | Суть |
|---|---|
| 💘 **Фанты** | Классика: по очереди тянете карточки «Правда» (вопрос) или «Действие» (задание), 6 уровней смелости — от «Знакомства» до «Фантазий». Есть счёт, избранное, отказ от задания и повышение уровня. |
| ❓ **Правда/Действие** | Тот же формат, что и Фанты, но с выбором типа карточки на каждый ход и отдельным набором заданий. |
| 💌 **Твои желания** | Каждый партнёр наедине с экраном отмечает «Да»/«Нет» на список желаний — видите только то, что совпало у обоих. Есть история совпадений за всё время — отдельные записи из неё можно удалять вручную красным крестиком. |
| 💑 **Тайные ответы** | Квиз на 10 вопросов (случайная подборка из банка в 300) об интимных предпочтениях, по нарастающей от лёгких тем к более откровенным. У каждого вопроса 3 варианта ответа плюс кнопка «Не хочу отвечать» (блокирует вопрос до сброса прогресса). Оба партнёра отвечают по очереди, наедине с экраном — в конце видно, в чём ваши ответы совпали (в том числе строка «Почти совпало» для близких, но не идентичных ответов). История совпадений за всё время тоже поддерживает удаление отдельных записей красным крестиком. |
| 🎱 **Ваше бинго** | Игровая карта 5×5 с заданиями. Собирайте линии по горизонтали/вертикали — сложность и бонусы растут по ходу игры. Кнопка «Случайно» подсказывает, какую клетку выполнить следующей, а собранные бонусы копятся в отдельном чек-листе. |
| 💞 **Пройди квест** | По очереди вытягиваете желания и решаете, готовы ли их исполнить. Сначала карточка знакомства с названием и описанием, кнопками «▶ Начать» (включает вопрос) и «Выход»; по «Начать» открывается первый вопрос квеста — «Да» засчитывает желание (+1 очко) с подсказкой, как всё сделать мягко и бережно, «Нет» приводит к более простому, безопасному следующему шагу. «Нет» на всех шагах — желание откладывается без давления. Каждое желание — своя ступень откровенности (уровень 1–10), а пройденное попадает в «Пройденные» — из него можно как продолжать с места остановки, так и удалить красным крестиком. |
| ⏱️ **Таймер страсти** | Задание показывается заранее, обратный отсчёт запускаете сами. Три режима: «Быстрая», «Продолжительная» (уровень растёт автоматически) и «Пользовательская» (время и повышение уровня настраиваете вручную). |
| 💃 **Предложи партнеру** | Листаете карточки 12 модулей: позы любви (4 уровня сложности, включая «В авто»), **Секс-шоп** (топ-150 популярных товаров с рейтингом), **Коллекцию** (109 позиций личной коллекции), **Желания женщины/мужчины**, **Советы сексологов**, **Идеи для вас**, **Ласки и позы камасутры**. Каждый модуль — отдельный уровень внутри игры. Понравившееся отмечается сердечком, отдельная кнопка «Избранное» открывает только отмеченные карточки. |
| 🎬 **Давай попробуем** / **Видеорулетка** | Два режима работы с видео из общего каталога: «Давай попробуем» — оба партнёра оценивают ролики («Да»/«Не сейчас»/«Нет»), совпавшие «Да» уходят в избранное; «Видеорулетка» — свободный просмотр того же каталога со свайпами. Своё видео можно добавить прямо с телефона. |
| 🎯 **Викторина** | Сначала все свои вопросы подряд отвечает один партнёр, затем телефон передаётся второму — 4 варианта ответа, верный один, кнопки «Пропустить» нет: не успели выбрать за отведённое время (10/15/20 сек на настройку, по умолчанию 15) — вопрос засчитывается как неверный. Тап по карточке озвучивает вопрос вслух (🔊), а кнопка ▶️ рядом с «Паузой» включает автоозвучку — тогда каждый новый вопрос проговаривается голосом сам, без тапа (есть во всех четырёх «Викторинах» приложения). Число вопросов на каждого игрока настраивается (3/5/7/10, по умолчанию 3), 4 уровня — 💗 «Романтика», 🔥 «Сближение», 💋 «Разогрев», 🌶️ «Откровенно 18+» (по 150+ вопросов на уровень). В конце — таблица результатов: верные ответы и суммарное время; если по числу верных ответов ничья — побеждает тот, кто отвечал быстрее. |
| 💬 **Ответы на вопросы** | Текстовые карточки с вопросами и развёрнутыми ответами сексологов (один вопрос-ответ на карточке). По очереди читаете и обсуждаете; понравившиеся отмечаются ☆ и попадают в отдельное «Избранное». |
| 🎀 **Карта страсти** | В разработке — кнопка временно показывает заглушку «Загляните позже». |

## Игры для компании

Большинство игр этого раздела используют общий список игроков (от 2 до 10 человек, поле «Игроки» в блоке «🎉 Игры для компании» на главном экране) — заполняете его один раз, а дальше выбираете, во что играть. Исключение — «Счастливый билет»: это игра для 2 фиксированных команд (в каждой мужчина и женщина), с собственным экраном настройки, не связанным с общим списком.

| Игра | Суть |
|---|---|
| 🐊 **Крокодил** | Шарады на компанию от 2 до 10 игроков. Один игрок показывает слово с карточки, остальные угадывают. Режим «Слово» (только предметы/существительные, молча жестами) или «Действие» (сценки, эмоции, профессии, тоже молча) — пулы карточек не пересекаются; есть и словесная разновидность без пантомимы — «Объясни словами» (объясняешь слово своими словами и описаниями, не называя его и однокоренные) — использует тот же пул, что и «Слово». Раунд на время (30 сек/3 мин/5 мин, по умолчанию 3 мин), количество карточек за раунд настраивается (по умолчанию 5). 4 уровня — 🧒 «До 12 лет», 🎈 «До 18 лет» (уровень по умолчанию), 🔥 «18+», 😈 «Похабные», всего 1015 слов (по 250 на каждый уровень, на 4-м — 265). Игра показывает полноценное итоговое окно с таблицей результатов по каждому игроку. |
| 🃏 **Мемасики** | Приложение показывает текстовую карточку-ситуацию — 415 карточек (по 100 на каждый из тех же 4 уровней, на 4-м — 115) — компания подбирает под неё самый смешной мем из своей физической колоды мем-карточек. Без таймера и счёта, просто «Далее»/«Скрыть». |
| 🎉 **Фанты (компания)** | Задания на всю компанию по кругу, 4 уровня смелости (по 100 заданий на уровень). «Выполнено»/«Отказ» ведут счёт по каждому игроку, итоговое окно показывает финальный расклад. |
| 🗣️ **Правда/Действие (компания)** | На каждом ходу игрок сам выбирает «Правда» или «Действие», 4 уровня (по 50 вопросов и 50 заданий на уровень). Тоже со счётом по игрокам и итоговым окном. |
| 🧠 **Знаю тебя** | Семейный квиз: от 1 до 3 семей (по 2 человека, с указанием пола каждого — для правильного склонения вопросов). Раунд — 10 вопросов, каждый про ОДНОГО конкретного игрока: он(а) отвечает как есть, второй угадывает его(её) ответ; за раунд у каждого партнёра ровно 5 вопросов в роли героя и 5 в роли угадывающего (порядок перемешан). В конце видно только число верных угадываний у каждой семьи — сравнение семей между собой в итоговой таблице. |
| 🎫 **Счастливый билет** | Общее игровое поле 5×5 (как в «Вашем бинго», 10 линий) на 2 команды — в каждой команде мужчина и женщина. Задания на клетках выполняет пара, открывшая клетку, — либо один партнёр для другого (исполнитель чередуется по ходам), либо задание совместное. Команды ходят по очереди и отмечают клетки; кнопка «🎲 Случайно» подскажет, какую клетку выбрать. Собранная линия приносит команде бонусное задание на двоих (попадает в накопительный чек-лист «🎁 Бонусные задания» под картой), а уровень повышается автоматически после 1-й и 3-й линии — от 💗 «Нежно» (лёгкие весёлые задания на публику, по 50 на уровень) через 😏 «Игриво» (флирт) до 🔥 «Дерзко» (смело и чувственно, разрешены поцелуи и касания любых мест тела, включая без одежды, но без прямого секса и без обнажения гениталий). Партия завершается сама после 5 собранных линий или всех 25 клеток — побеждает команда, отметившая больше клеток (победа сама по себе и есть приз), а проигравшую команду (если не ничья) ждёт самое горячее задание всей игры — финальный форфейт перед всей компанией. |
| 🎯 **Викторина** | Тот же формат, что и парная «Викторина» (каждый игрок по очереди отвечает на все свои вопросы подряд, потом телефон передаётся следующему), но участвуют все игроки из общего списка (2–10 человек). 4 уровня — 🧒 «До 12 лет», 🎈 «До 18 лет», 🔥 «18+», 😈 «Пошлые» (всего 626 вопросов: по 150 на 2–4-й уровни, на 1-м — 176). Итоговая таблица ранжирует всех игроков по числу верных ответов, а при равенстве — по суммарному времени ответов (быстрее значит лучше). |
| 🤸 **Твистер** | Цифровой аналог классического коврика: приложение объявляет ход («Вова, левая рука на синий») текстом и голосом, игроки физически выполняют его на настоящем/самодельном коврике. Игрок и цвет хода выбираются случайно. |
| 🎡 **Рулетка** | Казино-рулетка на компанию: у каждого игрока свой баланс фишек, ставки на числа/цвет/чёт-нечет, вращающийся волчок с анимацией и честным случайным результатом. |
| 🙊 **Я никогда не** | Классические признания на компанию: приложение показывает фразу «Я никогда не...», 4 уровня смелости (по 50 фраз на уровень, последний — самый откровенный). Компания сама решает, как поступает тот, кто узнал в фразе себя. |

## Игры с детьми

Игры этого раздела используют свой отдельный список игроков (от 2 до 10 человек, поле «Игроки» в блоке «🧸 Игры с детьми» на главном экране) — не связан со списком «Игры для компании». Там же — общий переключатель «Выберите возраст» (5 / 7 / 10 / 14 лет, по умолчанию 7 лет), от которого зависит подбор контента в играх этого раздела, которым это важно («Правда/Действие» и «Викторина» — у неё нет собственного выбора уровня, он всегда берётся отсюда).

| Игра | Суть |
|---|---|
| 🐊 **Крокодил (дети)** / 😂 **Мемасики (дети)** | Детские версии одноимённых игр компании — тот же формат, отдельный подобранный по возрасту контент. |
| 🧠 **Мемори** | Классическая игра на память для 2–10 игроков. Карточки лежат картинкой вниз; на своём ходу игрок открывает две — совпали, значит пара найдена, очко в счёт и ещё один ход, не совпали — карточки переворачиваются обратно и ход переходит следующему игроку. 4 уровня сложности (🧸 «Легко» — 6 пар, 🎈 «Средне» — 8 пар, 🚀 «Сложно» — 10 пар, 🏆 «Эксперт» — 14 пар), набор картинок каждую партию выбирается случайно из общего пула. Игра показывает итоговое окно с таблицей результатов по каждому игроку (игроки с одинаковым числом пар делят место). |
| 🗣️ **Правда/Действие** | Игроки по очереди выбирают «Правда» (ответить на вопрос вслух) или «Действие» (выполнить задание). Уровень контента берётся из общего переключателя возраста (5/7/10/14 лет) на экране «Игры с детьми» — вопросы и задания подобраны по возрасту. Игра открытая, без фиксированного конца: счёт по каждому игроку виден всё время, партия завершается только вручную через «Закончить игру» из меню паузы. |
| 🎯 **Викторина** | Тот же формат, что и остальные две «Викторины» (каждый игрок отвечает на все свои вопросы подряд, потом телефон передаётся следующему), участвуют все игроки из списка «Игры с детьми». Своего выбора уровня в настройке нет — вопросы подбираются по общему переключателю возраста (5/7/10/14 лет). По 150 вопросов на каждый возраст. |
| 💣 **Сапёр** | Настоящая сапёрская механика: на поле 5×5 спрятаны 💣-мины. Открывайте безопасные клетки — рядом с минами показывают число соседних мин, пустые зоны дарят весёлые семейные задания (автораскрытие похожих зон, как в классическом сапёре). Половина из оставшихся ячеек на уровне — зелёные клетки с надписью «вам повезло, пропустите ход». Задания выполняет только тот игрок, который попал на клетку. Поставьте 🚩 на подозрительную клетку (long press или правая кнопка мыши). Победа — раскрыть все безопасные клетки; поражение — врезаться на мину. С каждой победой уровень растёт (🔍→💥→🎉) и мин становится больше; за победу — финальный приз (семейное задание) в блок «🎁 Бонусные задания». «👀 Показать задания» раскрывает поле для подсмотра, «🎲 Случайно» подсказывает безопасную клетку. Четвёртая строка состояния показывает «Мимо» и другую информацию. |
| 🎲 **Во что поиграть?** | Карточки-подсказки с описанием классических настольных и словесных игр (Уно, Дурак, Крестики-нолики на бумаге, Морской бой, Города и другие) — если не знаете, во что поиграть без телефона. |
| ❌⭕ **Крестики-нолики** | Классика для двоих игроков — на выбор поле 3×3 (три в ряд побеждают) или 5×5 (для победы нужно четыре в ряд). Первый ход в партии случайный, дальше первым всегда ходит победитель предыдущего раунда. Счёт побед и ничьих ведётся по всей партии. |
| 🚢 **Морской бой** | Классический морской бой для двоих на поле 10×10 с передачей телефона между ходами. Флоты обоих игроков (1 четырёхпалубный, 2 трёхпалубных, 3 двухпалубных, 4 однопалубных корабля) расставляются автоматически и случайно, корабли не касаются друг друга. Попал — стреляешь ещё раз; промазал — ход переходит другому игроку; побеждает тот, кто первым потопит весь флот противника. Поле игрока 1 — в прежних цветах, поле игрока 2 — голубое; внизу экрана — строка статистики побед: «Игрок 1 победил: X раз», «Игрок 2 победил: Y раз» (счётчик сохраняется между партиями). Под заголовком крупной строкой показано, чей сейчас ход («Ходит: Игрок 1»), причём имена игроков в подписи окрашены по разному — активный (чей ход/кто держит телефон) выделен золотом. При передаче хода всплывает упрощённое окно «Передайте телефон игроку N» с кнопкой «Продолжить» — поле открывается сразу после начала игры. Кроме двухигроковой версии, в «Играх для одного» есть вариант против бота. |
| 🗂️ **Флеш-карты** | Игра «Флеш-карты» теперь живёт в разделе **«Игры для одного»** (см. таблицу ниже) — детская версия объединена с одиночной. |

## Бизнес игры

Обучающие мини-игры для тимбилдинга и деловых встреч — цель не только развлечь, но и на практике показать базовые принципы бизнеса (издержки, спрос, ценообразование, риски). Свой отдельный список игроков (от 2 до 10 человек).

| Игра | Суть |
|---|---|
| 🍋 **Лимонадный ларёк** | Симулятор жизни школьника с тележкой лимонада — 7 игровых дней (с понедельника по воскресенье). ## Общие для всех игр функции

- **Избранное** — в большинстве игр можно отметить понравившуюся карточку (☆/❤️) и позже вернуться к отмеченным отдельной кнопкой, не проходя игру заново.
- **Своё задание** — в Фантах можно добавить собственную карточку (уровень, тип, для кого, текст) через форму на экране настройки; сохраняется на устройстве.
- **Резервная копия** — в глобальном меню (☰) можно экспортировать весь прогресс (счёт, избранное, свои задания, историю совпадений и т.д.) в файл и импортировать его позже или на другом телефоне — данные не привязаны к серверу. Видео, добавленные в «Давай попробуем»/«Видеорулетку», в этот файл не входят (они хранятся отдельно, в IndexedDB устройства) — при переносе на другой телефон их нужно будет загрузить заново.
- **Единое меню паузы** — в любой игре кнопка «Пауза»/«Выход» (отдельный оранжевый стиль) открывает одинаковое окно по центру экрана: название игры, «Продолжить игру», «Закончить игру» и кнопка звука. Прогресс партии сохраняется, пока не нажато «Закончить игру».
- **Итоговые окна** — Крокодил, Фанты (компания), Правда/Действие (компания), Знаю тебя, Счастливый билет, Мемори, Крестики-нолики, Правда/Действие (дети, по кнопке «Закончить игру») и все «Викторины» по завершении партии показывают таблицу результатов по каждому игроку/семье.
- **Звук** — общая кнопка звука находится в глобальном меню (☰) и продублирована в меню паузы каждой игры; отдельных кнопок звука на экранах настройки игр больше нет (кроме «Видеорулетки», где своя кнопка нужна для управления звуком видео).
- **Кнопка «Выход»** — везде, где она есть, оформлена с красной обводкой для быстрой визуальной ориентации.
- **Скрыть задания** — в «Вашем бинго» и «Счастливом билете» кнопка «🙈 Скрыть задания» прячет текст на всех ещё не открытых клетках под иконкой; первый тап по скрытой клетке лишь открывает текст задания, следующий тап засчитывает её как выполненную.
- **Удалять вручную** — в историях «Совпадений» в «Твоих желаниях» и «Тайных ответах», а также в «Пройденных» «Пройди квеста» у каждой записи есть красный крестик: удаляет отдельное задание из сохранённой истории без сброса всего прогресса.
- **Таблица лидеров по уровням** — в «Мемори» (игра для одного) у каждого из 4 уровней сложности своя отдельная таблица лидеров: сохранённый результат содержит имя, время и уровень, а показывается только таблица текущего выбранного уровня.
- **Экран не гаснет** во время игры (Screen Wake Lock, если поддерживается браузером).
- **Сбросить прогресс** — возвращает в игру все скрытые (🚫) карточки, обнуляет память о показанных заданиях (включая игры для компании), очищает избранное, историю совпадений в «Твоих желаниях» и «Тайных ответах» и чек-листы «Пройденных» в «Пройди квесте». Свои добавленные задания в Фантах при этом сохраняются.
- **Имена игроков сохраняются** между сеансами: введённые в настройках групп игр имена не стираются при перезапуске приложения (сбрасываются только при «Сбросить прогресс» или ручном переименовании).
- **Закрыть правила** — в каждом окне правил в правом верхнем углу есть кнопка-крестик (✕), закрывающая окно сразу, без прокрутки до конца.
- **Детские крестики-нолики** — символ X в описании, на иконках и в интерфейсе детской версии всегда зелёный, как на игровом поле.
- **«Во что поиграть?»** — название игры на карточке выделено акцентным цветом и жирным шрифтом, отделено от описания.
- **Флеш-карты (топ-250)** — набор из 250 слов полностью независим от топ-100: в расширенный пул не попадают слова из базового.
- **Флеш-карты** переехали в «Игры для одного»; темы — 2 в ряд, иконки убраны со всех кнопок в меню игры; подпись блока темы — постоянная «Темы». В игре автоозвучка включена по умолчанию и находится в сворачиваемой строке «Дополнительно» (перед кнопкой «Правила»); перевод слова на карточке подсвечен золотым цветом.

## Установка на телефон

1. Откройте `index.html` в Safari (iPhone) или Chrome (Android) — можно переслать себе файл через AirDrop, iCloud Drive, Google Диск или сообщение.
2. **iPhone:** нажмите «Поделиться» (квадрат со стрелкой вверх) → «На экран «Домой»» → «Добавить».
3. **Android:** в меню браузера выберите **«Добавить на главный экран»** либо **«Установить приложение»** (Chrome предлагает установить, как только `sw.js` зарегистрируется и выполнит критерии PWA — в этот момент в глобальном меню (☰) появляется пункт «Установить приложение», который вызывает тот же системный диалог).
4. Готово — иконка появится на главном экране и будет открываться как обычное приложение, полностью офлайн, без строки браузера.

Подсказка «Установка на телефон» доступна и прямо в приложении — в глобальном меню (☰) пункт «Установить приложение» триггерит системный диалог установки (Chrome Android) либо открывает инструкцию (iOS, где системного API нет).

## Структура файлов

Все файлы и папки должны лежать рядом, в одной общей папке (пути в `index.html` — относительные):

- `index.html` — разметка и подключение всех скриптов; сама логика игр вынесена в папку `games/`.
- `manifest.json`, `icon-180.png`, `icon-192.png`, `icon-512.png` — PWA-манифест, иконки и Service Worker для установки и полной работы офлайн:
  - `sw.js` — сервис-воркер: при установке предкэширует **все** скрипты игр и карточки из `index.html`, так что всё приложение (включая «Пройди квест», «Ваше бинго», «Видеорулетку») работает офлайн сразу после установки, без первого онлайн-визита в каждую игру;
  - `manifest.json` — Web App Manifest с `id`, `categories`, иконками в том числе `maskable`;
  - `icon-180/192/512.png` — иконка для установки на телефон (iOS «На экран Домой», Android «Добавить на главный экран», а также Chrome «Установить приложение» в глобальном меню).
- `ИНСТРУКЦИЯ.md` — для разработчиков: как развёртывать, добавлять игры/карты и тестировать офлайн/PWA.
- `games/` — код каждой игры отдельным файлом (см. ниже).
- `cards/` — тексты заданий/карточек каждой игры отдельным файлом (см. ниже).
- `photos_poses/`, `photos_shop/` — папки с фотографиями для поз и товаров секс-шопа.

## Технические детали

- Без сервера, регистрации и интернета — всё работает локально в браузере.
- Прогресс (счёт, избранное, свои задания, история совпадений, добавленное видео) хранится на устройстве через `localStorage` и `IndexedDB`.
- Чтобы добавить карточки напрямую в файл (не через форму в приложении), откройте нужный `cards_*.js` и допишите запись по образцу уже существующих в этом же файле.
- Приложение запоминает уже показанные карточки на устройстве и не повторяет их, пока не покажет весь доступный пул — только после этого колода перемешивается заново.
- При повороте телефона игры с видео («Давай попробуем», «Видеорулетка») разворачиваются на весь экран горизонтально; остальные игры всегда остаются в вертикальной ориентации.
