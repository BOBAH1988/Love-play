# ТЗ по доработкам проекта (от лёгких задач к сложным)

4. Запоминать введённые имена игроков в настройках
   - Имена, которые пользователь вводит в настройках групп игр, должны сохраняться между сеансами.
   - Имена сбрасываются только при сбросе прогресса или ручном переименовании.

   после функции обновить игру, сбрасываются значения на по умолчанию, имена должны сохраняться

5. Флеш-карты: 
переместить в группу игр для одного
Вместо заголовка Темы написать (Английский язык):
ниже кнопки с уровнями по 3 в ряд -  Популярные слова(в них топ 100 или топ 250), Животные, Глаголы(удалить иконку), время(удалить иконку)
при фильтре от дублей, количество в топ 250 не сократилось? должно быть 250 слов в этой группе без дублирующихся с топ 100.
на карточке игры, под кнопками первого ряда, сделать модуль "Дополнительно" от должен быть скрытым по умолчанию, а при нажатии открывать юополнительные кнопки.
В него помести кнопки второго ряда - правила и выход
по умолчанию в игре включено автовоспроизведение звука. а кнопку эту помести перед кнопкой правила во второй ряд
перево слова на карточке сделай отдельым цветом например золотым как название в игре во что поиграть

6. Морской бой: 
во всплывающем окне - передать телефон, Сократи описание до - предай телефон игроку 1
скопировать игру морской бой в группу игры для одного, но вместо второго игрока сделать игру с ботом

7. Детская викторина: увеличить количество вопросов до 150 на группу
   - В каждом возрастном уровне (1–4) добавить вопросов до 150 штук.
   - Вопросы должны подходить по возрасту и не повторяться внутри уровня.
   Сделать рандом по другому, сейчас одни и теже попадаются особенно в начале игры после обновления приложения

8. Викторина для одного: добавить вопросы до 150 на уровень
   - В текущем банке вопросов для одиночной викторины добавить новые карточки.
   - На каждый уровень должно быть до 150 уникальных вопросов.

9. Флеш-карты: добавить модуль «Животные»
   - Новый модуль в выборе тем: животные.
   - Внутри модуля — популярные животные для обучения (название на английском, транскрипция, перевод).

10. Флеш-карты: добавить модуль «Глаголы»
    - Новый модуль: самые употребимые глаголы в разных склонениях/формах.
    - Карточки: инфинитив, транскрипция, перевод.

11. Флеш-карты: добавить модуль «Время»
    - Новый модуль с двумя подразделами: «Механические» и «Цифровые» часы.
    - Карточки с вопросами и ответами по пониманию времени: например, «14 часов → 2 часа» и т.п.
    - Подразделы реализовать как две кнопки-фильтра внутри модуля.

12. Морской бой: переделать интерфейс и механику
    - Убрать промежуточное окно с надписью «Передайте телефон игроку...» перед началом игры.
    - После начала игры сразу открывается поле.
    - Под названием игры на карточке показать имя игрока, который сейчас ходит — надпись крупная, как название игры.
    - После каждого хода показывать всплывающее окно «Передайте телефон игроку 2» с кнопкой «Продолжить».
    - Информацию об оставшихся кораблях сделать третьей строкой под именем игрока.
    - Игровое поле зафиксировать, чтобы оно не скакало вверх/вниз при изменении текста (например, при попадании/мимо).

13. Сапёр: переделать в настоящую сапёра (💣)
    - Поле 5×5 с скрытыми минами (🔍 5 мин → 💥 7 → 🎉 9); счётчики соседних мин рядом с минами, пустые зоны — весёлые семейные задания (flood fill, как в классическом сапёре).
    - Победа = раскрыть все безопасные клетки; поражение = врезаться на мину (💥). Уровень растёт с каждой победой (до 3).
    - Флажки 🚩: long press или правая кнопка мыши на закрытой клетке. «🎲 Случайно» подсказывает безопасную клетку; «👀 Показать задания» раскрывает поле для подсмотра.
    - Финальный экран победы с бонусным призом (задание добавляется в «🎁 Бонусные задания»); после поражения — «Сыграть снова» / «Завершить игру».
    - Кнопка «Выход» в игре переведена в левый нижний угол.
