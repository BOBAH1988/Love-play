# ТЗ по доработкам проекта

Отсортировано от лёгких задач к сложным. Выполнено и вынесено из списка: **задачи 1–11**.

## Чек-лист оставшихся задач

- [ ] **12. Морской бой: переделать интерфейс и механику**
  - Убрать промежуточное окно с надписью «Передайте телефон игроку...» перед началом игры.
  - После начала игры сразу открывается поле.
  - Под названием игры на карточке показать имя игрока, который сейчас ходит — надпись крупная, как название игры.
  - После каждого хода показывать всплывающее окно «Передайте телефон игроку 2» с кнопкой «Продолжить».
  - Информацию об оставшихся кораблях сделать третьей строкой под именем игрока.
  - Игровое поле зафиксировать, чтобы оно не скакало вверх/вниз при изменении текста (например, при попадании/мимо).

- [ ] **13. Сапёр: переделать механику и задания**
  - Половина из оставшихся неоткрытых ячеек на уровне должны быть зелёными клетками с надписью «Вам повезло — пропустите ход».
  - Задания выполняет только тот игрок, который попал на клетку с заданием (не оба сразу).
  - Игра заканчивается, когда все клетки открыты (а не только при собрании линий).
  - Добавить четвёртую строку состояния: отдельно показывать «Мисс» и другую служебную информацию.
