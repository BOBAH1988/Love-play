# ТЗ по доработкам проекта (от лёгких задач к сложным)

1. Флеш-карты: 
добавить модуль «Время» это не изучение английского языка а изучение времяни по часам
    - Новый модуль с двумя подразделами: «Механические» и «Цифровые» часы.
    - Карточки с вопросами и ответами по пониманию времени: например, «14 часов → 2 часа» и т.п.
    можно сделать задание и 4 разных варианта ответа например
    - Подразделы реализовать как две кнопки-фильтра внутри модуля.




2. Сапёр: 
вернуть прежнюю версию игры до выполнения тз

Переделать игру сапер. Половина из оставшихся ячеек на уровне должны быть зеленые клетки с надписью вам повезло пропусти ход. кто попадает на задание выполняет его. переделать задание. сейчас некоторые задание предлогаютя выполнять обоим игрокам, нужно чтоб задания выполнял только один игрок который попал на него. игра заканчивается когда все клетки открыты. строку состояния можно сделать четвертой: мимо и другую информацию
