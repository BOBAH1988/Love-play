# ТЗ по доработкам проекта:

сделать симулятор биржи акций в бизнес играх, цель научиться управлять акциями и понимание рынка, реализуй как видишь потом будет доделывать, нужна временная шкала с переключением, выбор популярных акций, и их случайное поведение в цене. цель научиться вложениям в акции понят от какого срока стоит рассматривать вложения, учесть налоги на доход с прибыли. и другие важные функции для общего понимания.

создать динамичиские ссылки чтоб можно было поделиться только одной игрой или группой игр, без возможности им открыть все игры

Уровни доступа:

Уровень Кто это Что может

`guest`Гость без регистрацииВидит все группы и игры, но не может запускать игры 18+

`starter`Зарегистрированный пользователь - доступны все игры из игр для компании кроме последнего уровня, в играх для пар доступны только 2 первых кровня

`plus`Пользователь расширенного уровня

`premium`Премиум-пользователь - видит все кроме исключенний, сейчас исключений пока нет

`dmin`АдминистраторМожет запускать все игры, включая 18+, при условии `isAdult: true`
